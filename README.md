# LLM Wiki Releases

LLM Wiki 데스크톱 앱의 설치 파일과 자동 업데이트 정보를 배포합니다.

- [최신 설치 파일](https://github.com/Jong-Yu/llm-wiki-releases/releases/latest)
- [소스 코드와 실행 안내](https://github.com/Jong-Yu/llm-wiki)

앱 프로젝트에서 `npm run release -- --mac --win`으로 게시합니다. `latest.yml`, `latest-mac.yml`과 블록맵은 앱 자동 업데이트에서 사용하는 배포 파일입니다.
